# **App Name**: BlankCanvas

## Core Features:

- White Webpage: A white empty web page template

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to evoke a sense of calmness and creativity.
- Background color: Light gray (#F5F5F5), nearly white, to maintain a clean, distraction-free canvas.
- Accent color: Pale pink (#FFB6C1) for subtle highlights and interactive elements.
- Body and headline font: 'Inter' sans-serif for a clean, modern, neutral, and easily readable look.
- Use simple, minimalist icons for content blocks and formatting options.
- Clean, open layout with ample whitespace to focus user attention on the content.
- Subtle fade-in effects when inserting content blocks to provide visual feedback without being distracting.
